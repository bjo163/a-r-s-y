# A-R-S-Y — Brand System v1

## Brand core

- Name: A-R-S-Y (compact UI wordmark: ARSY).
- Category: Open Hybrid Cloud Control Plane.
- Tagline: One command plane. Open by design.
- Indonesian tagline: Satu kendali. Infrastruktur terbuka.
- Supporting line: Build it. Route it. Protect it. Own it.

## Values

1. Sovereignty: customer control and portability first.
2. Clarity: show real resource, usage, and incident state.
3. Resilience: design for failure and recovery, not only demos.
4. Openness: no mandatory source-available or proprietary dependency.
5. Adab and restraint: MoonWitness inspiration is handled respectfully, never as a marketing gimmick.

## Personality

Confident, precise, independent, technical, calm under pressure, slightly rebellious. Avoid fake cyberpunk noise, exaggerated claims, corporate fluff, and pseudo-spiritual marketing.

## Visual direction: MoonWitness Industrial Cosmic

Premium control-room identity with MoonWitness comic/grunge DNA:
- Geometric mark, routing lines, orbit arcs, topology maps, signal points.
- Neo-brutalist information hierarchy with disciplined spacing.
- Dark and light themes from the beginning.
- Manga/comic artwork for storytelling and campaign visuals, not as noise behind operational data.
- No decorative text-HUD overlays or low-contrast microcopy.

## Palette

- Void: #090D12.
- Carbon: #151C24.
- Signal: #69F0D0.
- Solar: #FFB45C.
- Paper: #E8E6DE.
- Muted: #9AA9B5.

The logo is an abstract central node with four converging paths inside a structural frame. It is a concept mark, not trademark clearance. It does not depict a sacred or metaphysical object.
